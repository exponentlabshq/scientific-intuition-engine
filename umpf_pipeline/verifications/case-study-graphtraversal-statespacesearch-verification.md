## What was found

This is closer to restatement than bisociation. Every standard AI-education source found (GeeksforGeeks, Scaler, ScienceDirect Topics) describes graph traversal algorithms (BFS/DFS/A*) as *literally the standard techniques used to perform* state space search: "State space search is a conceptual framework... search algorithms such as BFS and DFS are techniques used to explore the state space." State space search *is* graph traversal, applied to a problem-space graph — not two "habitually incompatible frames of reference" (Koestler's own bar, quoted in this project's own bisociation prompt) but a framework and its standard implementation technique.

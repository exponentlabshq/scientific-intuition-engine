# Eureka Engine — Researcher Outreach (Phase 3)

**Status across the board: drafts may exist; nothing is auto-sent.** Same discipline as
`Deals/sayve/outreach/` — one file per contact or packet, drafts only, sending is
Michael/Rocky's call every time.

**COA 1 (research mission):** packets live in `packets/`. Shortlist (no self-report ranking)
is regenerated by:

```bash
python3 score_hypotheses.py --outreach --outreach-limit 10
```

## When a hypothesis gets a draft

Only **ADJACENT_ACTIVE** (Frontier Research Group) candidates — preferably with
actively researched evidence. Prefer bisociation/homospatial over twice-flagged janusian.
COLLISION / FACT_CHECK_FAIL / REFUTED do not get drafts.

## COA 2d — Send-ready gate (sharpen → re-verify)

Lightning ×2 (2026-08-29): soft ADJACENT often looks sendable; closed-loop sharpen + denser
search shows the soft claim is near-known while the hard chimera may still be adjacent.

**A packet is send-ready only if all of:**

1. Verdict is `ADJACENT_ACTIVE` on the **hard** claim after denser re-verify  
2. Hypothesis file has a `**Revision**:` / human-sharpened closed-loop banner  
3. Verification names **soft vs hard** (soft near-COLLISION neighbors; hard still adjacent)  
4. Email body pastes the **hard claim only** (never the soft §3/§4)

Soft-only packets (drafted before COA 2d) are tagged `sharpened: false` /
`NEEDS_SHARPEN` in `packets_manifest.json` — do not send until sharpened.

```bash
# Checklist / apply revision banner + stub
python3 sharpen_hypothesis.py hypotheses/<slug>.md --checklist-only
python3 sharpen_hypothesis.py hypotheses/<slug>.md \
  --soft-retired "..." --chimera "..." --hard-claim "..." --apply
```

Exemplars: Resonant Swarm; Magneto-Operant Schedule.

## Packet contents

See `packets/*.md`: hypothesis, generative relation, Phase 2 evidence, queries,
candidate contact fields, draft email, **NOT SENT** banner.

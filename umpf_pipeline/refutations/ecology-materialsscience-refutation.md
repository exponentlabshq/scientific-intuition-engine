# Adversarial Refutation: Bisociation — Ecology × Materials Science

**Original**: `hypotheses/2026-08-29-ecology-x-materials-science.md`
**Method**: 3 independent agents, one per lens, blind to each other

## Tally: 0 of 3 survive → **REFUTED**

All three lenses independently identified the same equivocation: "oscillation" is doing the bridging work,
but predator-prey cycles and phase transitions are not the same kind of oscillation.

- **Coherence — REFUTED.** Lotka-Volterra predator-prey cycles are sustained, self-referential limit-cycle
  behavior from coupled nonlinear feedback — no external driver required. Standard phase transitions are
  not oscillatory at all; they are one-way, threshold-crossing state changes driven by an external control
  parameter (temperature/pressure) crossing a critical point, governed by free-energy minimization
  (Landau/Ising-type mathematics), a structurally different formalism. §3's claim that the "SAME
  differential equations" govern both has no support in the literature and the hypothesis's own §6 concedes
  the gap without resolving it.
- **Testability — REFUTED.** No named model, fitting procedure, dataset, or quantitative alignment
  criterion is given — "to see if predictions align" doesn't define what "align" means. The "or vice versa"
  hedge means a failure in one direction can always be waved off as the other direction being the "real"
  test.
- **Triviality — REFUTED.** "Two systems oscillate, therefore the same equations apply" is satisfied by
  pendulums, AC circuits, business cycles, and chemical clocks alike. No shared derivation, conserved
  quantity, or bifurcation structure is offered — only the shared word "oscillation."

## No steelman offered

A narrower, defensible version would need to identify a specific class of phase transition that is
genuinely oscillatory (e.g., limit-cycle behavior in far-from-equilibrium chemical systems, which does
share real mathematical structure with population dynamics) rather than standard equilibrium phase
transitions — the hypothesis as written does not make this distinction and none of the three lenses could
rescue it from the text as given.

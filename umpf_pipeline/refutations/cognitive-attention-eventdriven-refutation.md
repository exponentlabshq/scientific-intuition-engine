# Adversarial Refutation: Bisociation — Cognitive Attention Map Evolution × Informational Event-Driven Systems

**Original**: `hypotheses/2026-08-29-cognitive-attention-map-evolution-x-informational-event-driven-systems.md`
**Method**: 3 independent agents, one per lens, blind to each other

## Tally: 0 of 3 survive → **REFUTED**

All three lenses converged on the same root problem: the functor's four layer-mappings reuse words
("uncertainty," "resource," "management") across the two domains without preserving any shared mechanism.

- **Coherence — REFUTED.** "Uncertainty-in-attention-allocation" (subjective, probabilistic salience
  shaped by goals/arousal/habituation) is mapped to "uncertainty-in-event-triggers," but canonical
  event-driven systems have no epistemic uncertainty — a condition is met or it isn't. "Cognitive-resource
  interaction" (a psychological capacity limit) and "system-resource interaction" (CPU/memory scheduling)
  are both called "resource contention" with no shared formal mechanism cited. The hypothesis's own §6
  self-critique (qualitative/subjective vs. quantitative/deterministic) is itself an admission that shared
  vocabulary is doing the mapping's work.
- **Testability — REFUTED.** No metric, cognitive task, or event-driven system is named to instantiate the
  comparison; "measuring performance metrics in both contexts" names neither a metric nor a baseline. The
  "or vice versa" hedge means any observed correlation in either direction — or none — can be narrated as
  consistent with the hypothesis. No outcome is forbidden.
- **Triviality — REFUTED.** Strip "attention" and "event": uncertainty, evolving state, resource-controlled
  interaction, orchestrated management are true of a thermostat, a database transaction log, or a vending
  machine equally well. The functor re-describes "stateful system with bounded inputs and a controller" in
  two dialects and calls the coincidence a mapping.

## No steelman offered

No lens found a narrower, rescuable version of this pairing. If revisited, it would need an actual
quantitative bridge (e.g., a specific attention model's mathematics mapped onto a specific event-scheduling
algorithm's mathematics), not the general shape of "both domains have state that changes."
